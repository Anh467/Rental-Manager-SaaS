# Rental Manager SaaS

Multi-tenant rental management platform.

## Frontend

The React client is located at `src/client/RentalManager.Client`.

```bash
cd src/client/RentalManager.Client
npm install
npm run dev
```

The reusable form architecture is documented in
[`docs/frontend/common-form-system.md`](docs/frontend/common-form-system.md).
